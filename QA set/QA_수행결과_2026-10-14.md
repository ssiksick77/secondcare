### 2.3 오류·경고 사례 (validate)

- X01~X18: 18건 전부 400 거부, 장부 스냅샷 불변. 메시지는 대부분 한국어·필드명 포함. X05(예산목)는 허용 값까지 제시한다.
- W01~W05: 5건 전부 200 저장, API 경고 응답 없음. W01 음수(-1) 저장, W02 잔액 0 재원에 1원 저장(잔액 -1), W03 기간 밖 날짜 저장, W04 미등록 재원 `QA_UNKNOWN` 저장 후 대시보드에 "예산 0 · 집행 10,000" 행 표시, W05 동일 관리번호 중복 저장. 같은 장부에서 금액 0(X04)은 거부되므로 음수 허용과 정책이 어긋난다.
- 데이터셋 품질: `/api/all` 15개 컬렉션 건수가 `app_readback.json`과 일치, 거래번호 147건 집합 동일, `record_ids.json` 기준 행 206/206 일치. `*-CONFIRM` 12건은 baseline 행이 없어 설명 보완이 필요하다.
