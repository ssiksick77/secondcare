## P2 — 수정 권장
**동작·견고성**
- 승인된 건을 담당자가 수정해도 승인·결재인이 유지됨(서버도 허용). 품목·단가·수량·금액·관련과제 변경 시 신청으로 되돌리거나 확인 요구.
- 외부(Excel)에서 연결 품의를 지우면 신청이 영구 `품의전환`으로 고착(전환·취소·삭제 모두 거부). `request_status`에서 연결 번호가 없으면 승인으로 간주.
- 연도 넘김: 2027-01-05 신청 저장 시 토스트만 뜨고 목록(연도 필터 2026)에 안 보임. 1월부터는 전년도 대기 건이 기본 화면·배지에서 사라짐. 저장 연도로 필터 전환, 대기 배지는 전 연도 합산, "이전 연도 대기 n건" 표시.
- 선택 바 일괄 처리: busy 가드 없음(더블클릭 → 충돌 토스트), 행마다 전체 저장 0.3–1.8s, 진행 표시 없음. 선택 바 비활성 + "승인 중 3/12", 장기적으로 일괄 action 엔드포인트.
- 반려 사유 비우면 대화상자가 닫히고 토스트만 → 대화상자 안에서 검증(열린 채 인라인 오류). 반려 버튼은 되돌릴 수 있는 동작이므로 빨간 danger 대신 primary.
- 첨부: 목록 조회 실패가 "드라이브 미연결"로 표시됨 / 네트워크 실패 시 영어 "Failed to fetch" / 25MB 검사가 전송 후에만 / 업로드 중 드롭 시 재제출 / 총량·개수 상한 없음.
- 다른 창의 변경은 탭이 다시 보일 때만 반영. focus 시에도 갱신 또는 30–60초 meta 폴링. 충돌 메시지 "다시 수정하세요" → 동작 중립 문구.
- 선택 바 비활성 버튼 사유가 title 툴팁에만 있음 → `#req-sel-why` 라이브 영역에 첫 차단 사유 표기.
- 신청인(datalist 필드)에 `required`가 안 붙고, 첫 포커스가 품목으로 가서 빈 신청인을 건너뜀.

**화면·문구**
- 장비 탭에 항상 빈 **주문번호** 열·드로어 "주문 -" 행 → 소모품에서만 표시(구매처와 동일 처리).
- 선택 바가 선택 없음일 때도 비활성 버튼 5개를 상시 노출 → n=0이면 버튼 숨김 또는 선택 시에만 표시.
- 드로어에서 결재 동작이 정보 13행 아래(1280×720에서 y=629) → 결재 섹션을 맨 위로, 상태 배지 중복(제목·h3) 제거.
- 체크한 행에 선택 배경 없음 → bg-select, 드로어 행은 좌측 2px 바로 구분.
- "담당자" 역할 표시가 헤더 버튼과 같은 테두리라 버튼처럼 보임 → 테두리 없는 텍스트.
- 1280에서 드로어 열면 [신청 추가]만 둘째 줄로 떨어짐 → 합계·CSV·추가를 한 묶음으로.
- 빈 상태 문구 분리: 필터 결과 없음 "조건에 맞는 신청이 없습니다" / 첫 사용 "아직 장비 신청이 없습니다. [신청 추가]로 시작하세요".
- 상태 **신청**이 화면·레코드·버튼·신청인과 겹쳐 "신청 상태의 신청"이 됨. 탭 배지는 이미 "결재 대기"라 한 상태에 이름 둘. 표시명을 **승인 대기**로 통일(저장값은 유지) — **사용자 결정 필요**.
- 연구원에게 **품의전환**이 설명 없이 보임 → "담당자가 구매 품의(결재 문서)를 올렸습니다. 더 할 일은 없습니다."
- 연구원 드로어의 삭제 불가 문구 "(담당자는 승인 취소 후)"는 담당자용 → "승인된 신청은 지울 수 없습니다. 취소가 필요하면 담당자에게 알려 주세요."
- 연구원 안내문을 흐름 중심으로: "① [신청 추가]로 품목·금액·사유 ② 행을 눌러 견적서 첨부. 승인되면 품의로 넘어가고 집행이 끝나면 완료. 승인 전에만 수정·삭제." 저장 토스트도 "신청했습니다. 견적서는 행을 눌러 첨부하세요."
- 연구원 모드에 장부 파일 경로·수정 시각·"엑셀에서 열려 있음" 노출 → 제목 "지출 신청", 경로 숨김, 잠금 문구는 "지금은 저장할 수 없습니다. 담당자에게 알려 주세요."
- 단가 힌트 "(원, 부가세 포함)" — VAT 규칙 **사용자 확인 필요**. 관련과제 힌트에서 '재원' 용어 제거.
- 품의 전환 / 품의전환 표기 통일. 혼합 선택 일괄 승인 시 건너뛴 건수 안내. 서버 오류 문구: 숫자 검증이 "금액"으로 고정 표기(실제는 수량/단가), 빈 예산목이 "'' 은 목록에 없습니다"로, 연결 품의 정리 안내 문구 둘 불일치.

## P3 — 다듬기
- 금액 상한·유한값 검사 없음(1e20 저장, "1e400"은 400이지만 행은 기록돼 재시도 시 중복), 수량 소수 허용, 0원 신청은 승인되나 전환 불가, 32,767자 초과 조용히 잘림(maxlength 없음), 과거 희망일·신청일 이전 결재일 허용.
- 마지막 번호 삭제 후 같은 신청번호·드라이브 폴더 재사용 → 연도별 최고 번호 보관, 업로드에 expect 추가.
- 첨부 확장자 미정제(`a.p:df` → NTFS ADS 파일), 첨부 업로드·삭제가 서버에선 모든 상태에서 허용.
- API에 역할 검사 없음(연구원 모드는 body 클래스뿐). 최소한 README에 명시하거나 헤더 토큰으로 action/convert/order/delete 보호.
- 상태 점 정렬(품의전환 배지 min-width), 반려 사유 빨간 글자 중복·JS 16자 절단, 첨부 열 가운데 정렬·0은 "-", 품목 라벨 "품목*" 공백, 금액 미리보기 좌측 정렬, 반려 확인창에 품목·금액 표시, 드로어 푸터 이중 선, 토스트가 헤더 버튼 가림, Esc가 메모 입력 중에도 드로어 닫음, 드로어 제목을 h2로, 결재 열이 항상 "담당자".
- 문구: 재신청 토스트, 희망일 "(필요한 날짜)", 첨부 안내 "견적서·사양서", 드롭존의 드라이브 경로는 담당자만, "입력 취소" 대화상자의 취소 버튼을 "계속 입력", 알림/토스트 용어 통일.
