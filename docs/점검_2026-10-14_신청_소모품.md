## P2 — 수정 권장
**동작**
- 결제금액 0 + 적립금 사용 → 적립금 검증 오류 "금액은 0보다 커야 합니다"로 실패. 주문 생성에서 먼저 검사하고 안내.
- 배송일 < 주문일, 주문일 < 결재일 허용 → 서버 검증 + date input min.
- 주문 생성 중 다른 곳에서 승인 취소되면 "목록을 새로 불러왔으니"라 하지만 대화상자·목록 그대로 → 404면 닫고 load().
- "주문 묶음 = 품의 1건" 미강제: 묶음 일부만 전환 가능, 여러 주문을 한 품의로 섞임, 품의 금액이 신청 합계(결제금액의 할인·배송비 반영 안 됨) → 주문 묶인 건은 전체 묶음·단일 주문 요구, 금액 기본 = 결제금액.
- 설정에서 구매처 이름을 수정하면 OFF 상태가 풀림(키 입력마다 재계산) → 이름 기준 Set 유지, change 시 재렌더.
- 구매처 이름 변경 시 적립금 잔액이 옛 이름에 남음 → 문서화 또는 일괄 치환.
- 취소된 주문번호 당일 재사용 → 접두·날짜별 고수위.
- 발주서 열린 채 Ctrl+P → 주문 화면 가로 출력 + 모달 배경. beforeprint에서 printing-sheet 처리.
- 신청 모드 인쇄 머리글이 숨은 대시보드 탭 기준이라 "예산현액 0 · 집행 0"이 찍힘 → request-mode는 연도·거래처·상태로 머리글.
- 주문 생성 줄 표가 긴 품목 때문에 수량·금액이 가려짐 → fixed layout + 말줄임.
- 구매처 OFF 중 열린 폼은 서버 거부 후에도 select에 "(이용 불가)" 미표시 → meta 갱신.
- 주문 보기 연도 필터가 전년도 미배송을 숨기는데 배지는 전 연도 합산 → 배송 전은 연도 무시.
- 주문 대화상자 오류가 토스트에만 → 인라인.
- 단일 잠금 파일(공유 불가) 시 500 + 전체 경로 노출 → PermissionError를 LedgerLocked로.
- rows:["abc"] → 원문 int 오류 노출. 상품링크는 trim + `^https?://` 검증 후 저장.

**화면**
- 드로어 값과 보조 글자가 붙음("드림-20261010-01주문 10/10", "드림디포(현재 이용 불가)") → kv span column-gap 6px.
- 주문 대화상자 라벨의 small 때문에 입력 칸 높이가 20px 어긋남 → `<span class="lab">` 패턴.
- 폼의 구매처 안내문 여백 과다, select 홀로 1/3 폭 → 안내문을 select 옆 2칸 span.
- 주문 표에 합계 행 없음(이중선 규칙 위반) → tfoot 합계(건수·주문금액·결제금액).
- 작업 열 가운데 정렬로 [발주서] 위치가 행마다 12px 흔들림 → 좌측 정렬 또는 고정 폭. [등록] 링크 25×16px 너무 작음, 버튼에 주문번호 aria-label 없음.
- 적립금 열 "사용"을 적립금 탭과 같은 배지로. 결제금액 볼드 제거(여백선 열만 볼드). 링크 스타일 2종 혼재. 선택 바 1px 높이 변화.
- 구매처 안내문이 select와 프로그램적으로 연결 안 됨 → aria-describedby.

**문구**
- 행 버튼 [취소] + 확인창 [취소][주문 취소] → 행 [주문 취소], 확인창 닫기 버튼 [그대로 두기]. 쇼핑몰 주문은 별도 취소해야 한다는 한 줄 추가.
- [배송 취소]는 날짜만 지우는데 배송 자체를 취소하는 듯 → [배송일 지우기], 확인 없이 즉시 실행 중이므로 토스트 명확히. 서버 메시지도 그 버튼 이름으로.
- 연구원 드로어 "주문 …를 먼저 취소하세요" → 연구원은 취소 불가: "주문에 묶인 신청은 지울 수 없습니다. 담당자에게 알려 주세요." 조사 오류("-01를"→"을").
- OFF 구매처 서버 오류가 담당자 지시문으로 시작 → 연구원 대상 문장으로, 담당자 안내는 괄호. 담당자 폼에서는 오류가 두 번(폼+토스트) 표시.
- 상태 필터 "주문 중/배송 완료" vs 다른 곳 "배송 전" → "배송 전/배송 완료".
- 안내문 중복 "드림디포는 10월 말까지 이용 불가 · 현재 이용 불가: 드림디포" → 안내가 있으면 안내만.
- 연구원 안내에 주문 단계 설명 추가. 선택 바 도움말에 [주문 생성] 언급. "주문 전 승인된" → "승인됐고 아직 주문하지 않은".
- 결제금액 placeholder "0"과 "(비우면 주문금액)" 충돌 → 힌트 "(할인·배송비 반영한 실제 결제액)". "적립금 사용으로 기록(…증빙번호 = 주문번호)" → "적립금으로 결제 (적립금 탭에 '사용' 1건 기록)", 사용자 칸 용도 표기·미체크 시 비활성.
- "부가세 구분 입력" → "부가세 별도 (쇼핑몰 가격이 공급가일 때)". 온라인코드·상품코드·상품링크 힌트 추가.
- 승인된 드림디포 신청 드로어 "(현재 이용 불가)" → "(새 신청 불가 · 이 신청은 그대로 진행)".
- 발주서 "담당자이(가) 비어 있습니다" 조사 오류, "출력" → "출력일". 설정 체크박스마다 "현재 신청 가능" 반복 → 그룹 라벨 하나.
