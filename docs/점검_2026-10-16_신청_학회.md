## P2 — 수정 권장
**데이터·서버**
- 승인된 학회 건의 상세(기간·장소·계산 입력)가 바뀌어도 승인 유지 → D2에 따라 `REAPPROVE_COLS`·`REQ_APPROVAL_KEYS`에 상세 포함 (store.py 96·1599, request.js 11).
- `종료일 < 시작일`을 서버가 검사하지 않음(클라만) → `_validate_request`에 날짜 형식·순서 검사 (store.py 1395-1403).
- 학회 금액 0 저장·승인 가능하나 품의전환에서 "금액은 0이 될 수 없습니다" → D7.
- 계산 적용 뒤 폼의 등록비·시작일·종료일을 고치면 상세 상단값과 `in/out`이 어긋남(합계 불변). 계산기에서 등록비를 0으로 지워도 폼 등록비는 옛 값 유지(`if (o.등록비 > 0)`) → 적용 시 0도 반영, 계산기 열 때 폼의 기간·장소 변경을 `in`에 병합, 저장 시 어긋나면 "계산기에서 다시 계산" 오류 (request.js 421, conf.js 658-693).
- 학회 금액 소수 허용(1234.5 → 품의 전파) → `_won_int` 적용 (store.py 1344).
- API 편집으로 단가·수량이 남은 채 금액과 따로 저장 → 학회면 서버가 단가 "", 수량 1로 정규화 (store.py 1342-1350).
- 두 탭 충돌 시 폼이 오류 문구만 보이고 새로고침 수단 없음(드로어 승인 충돌은 자동 재로드) → 토스트에 [새로 불러오기] (app.js 798-823).
- 품의전환·완료 건에서 연구원 첨부 업로드 버튼이 활성이나 서버 거부 → `canUp`에 상태 조건 (request.js 694).
- 품의 전환 preset이 학회 정보를 버림 → D3 (request.js 532-545).

**계산기**
- `cityGrade`가 가·나·다·라 외면 식비·총액 NaN(저장 JSON 손상 시) → 유효성 검사 후 missing (conf.js 252-255).
- 알 수 없는 통화 코드는 조용히 KRW 취급 → 미등록 코드면 오류 (conf.js 151).
- 당일 국외 출장 + 숙박 결제액 → "상한 0원까지만 반영" 문구 → 0박이면 "인정 박수 0박이라 숙박비 미반영" (conf.js 278).
- 이동 구간 순서 뒤바뀜(구간 i 출발 < 구간 i-1 도착) 미검사 → 주의 메모 (conf.js 220-231).
- 계산기 Esc/취소가 변경 내용을 확인 없이 버림(폼 금액은 안전) → 변경 시 1회 확인 (conf.js 730, 769).
- 폼 행 [계산 초기화]와 대화상자 [계산 초기화] 둘 다 있고 동작이 다름 → 폼 행 하나로, 금액 비우고 공통 토스트 (conf.js 709-712, 733).
- 적용 시 폼 등록비를 계산기 값으로 소리 없이 덮어씀 → 토스트에 "등록비 N원으로 바꿨습니다" (conf.js 691).
- '계산하려면' 미입력 목록이 글자뿐 → 항목을 버튼으로 만들어 해당 칸 focus, `aria-invalid` (conf.js 541-544).
- 이동 구간 Tab 순서가 출발 → 기내식 → 삭제 → 도착(rowspan 셀 위치) → 기내식·삭제 셀을 두 번째 행 끝으로 (conf.js 377-389).
- 1024px에서 이동 구간 표 가로 넘침(953 > 935), [삭제] 잘림 → 시간대 select 200px, 장소 100px (style.css 772-776).
- 국내 모드 요약 띠 "숙박 지역: 서울특별시 (상한 100,000원/박)" 두 줄 → 상한은 보조 줄 (conf.js 526).
- 대화상자 폭 1180px가 DESIGN 규격(780px) 예외인데 미기록 → DESIGN.md에 명시 (style.css 743).

**폼·목록**
- 폼 칸 순서(금액·계산기가 학회 상세 위) → D6. `_국내외` 기본값 → D4. 참가자 복수 → D5.
- 목록 학회 탭: 머리글 "품목"(폼·드로어는 "학회명"), 수량 열 항상 1, 품목 아래 줄이 규격/사유 → 수량 숨김, 머리글 학회명, 아래 줄 "기간 · 장소"; 기간 열·정렬 추가 (request.js 37-52).

## P3
- 구분 학회→장비로 바꿔도 서버는 상세를 지우지 않음 → 구분≠학회면 상세 "" (store.py 1395). 상세에 JSON 배열 허용 → dict만 (store.py 1396). `상세.합계`만 있고 v/in/out 없으면 금액 잠김 + 초기화 버튼 숨김 → 잠금 조건을 `calc != null`로 (request.js 362). `mcp_server.update_row` 설명에 request 포함 명시.
- 계산기: 기내박 직접 입력에 숫자 아닌 값 → 0박 처리(자동값 유지로), 제공 식사 소수 허용(정수화), 음수 금액 조용히 0(거부 표시), `validTz`가 "EST" 같은 비-IANA 이름 통과, DST 겹침 시각 안내 없음, 제17조 기산일이 환승지 도착일(참고 원본과 동일, 첫 체재지 기준 고려).
- 외부지원금 > 산출액이면 총액 0인데 라인 합계는 음수 → 인쇄물에 설명 한 줄.
- 드로어에 금액이 세 번 표시 → 여비 계산 행은 "산출 내역 보기"만. 연구원 안내문·첨부 안내가 장비용 문구("견적서") → 학회는 "초청장·등록 인보이스·e-티켓" (index.html 163, request.js 702). 신청인 열 64px 말줄임.
- 접근성: h3 "이동 구간" 안의 설명문을 밖으로, `#dlg-conf`에 aria-describedby, 요약 띠 aria-live는 총액 카드만. 인쇄 머리글에 센터명 없음, 괘선·머리글 색이 발주서(#000)와 다름 (style.css 893). 6구간 인쇄 2쪽에서 산출 내역 표가 쪽 경계에서 갈림 → `break-inside: avoid`.
- 검색이 상세 JSON 내부 키(`KRW`, `intl`, `Europe/Paris`)까지 매칭 → 학회는 학회명·장소·참가자만 색인 (app.js 242). 학회 신청 저장 토스트에 [되돌리기] 없음 → `{undo:true}`. 토스트가 뒤이어 연 모달에 가려짐.

## 잘 된 점
- 산식·규정표·절사·정산 기한이 참고 원본과 1:1 일치, 라인 합과 총액이 항상 같음. 시간대 처리(DST 갭 보정, 역전 경고, 누락 차단)에 크래시 없음.
- 금액 잠금 규칙이 일관됨: 계산 적용 → 저장 → 재열기 → 비금액 수정 → Ctrl+Enter 연타까지 합계·상세 동일, 이중 제출에 1건만 생성, 계산 초기화 후 수동 금액 저장 시 v/in/out 정리.
- 서버 충돌 보호(`_snapshot`)와 상태·결재 열 강제(API로 상태·부가세를 넣어도 무시), 첨부 포함 삭제가 mock 휴지통으로 이동, 보기 전용 모드가 강제 입력에도 불변.
- v:1 → v:2 통화 호환, 폼 → 계산기 시드(장소로 시간대·등급 자동), 포커스 복귀가 일관됨.
