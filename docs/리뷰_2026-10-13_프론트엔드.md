# 프론트엔드·기능 리뷰 (2026-10-13, 2차)

참여: opus-1(실무 담당자 일상 흐름), opus-2(센터장·월 마감 보고 숫자), sonnet(UI 일관성·접근성), haiku(신규 사용자·문구·README). fable이 각 보고를 코드로 대조해 취합. 백엔드는 범위 밖. 리뷰어가 제출한 항목 중 코드와 맞지 않는 것은 제외하고, 같은 항목은 합쳤다.

## 2. 다음 버전 기능 제안

### 우선 (작은 노력, 큰 효과)
1. **기준일/마감월 선택기** (M): 가용잔액·대기 품의·선급/미지급을 한 기준일로 계산하고 머리줄에 인쇄. A1~A3·A7을 한 번에 정리.
2. **첫 실행 체크리스트와 예산 미입력 경고** (S): 재원→예산→태그→드라이브→첫 집행. 집행은 있는데 예산현액 0이면 칸과 폼에 "예산변동에서 입력" 링크.
3. **인건비 월 단위 일괄 확정** (M): 월(·지급처) 선택, 지급일 하나로 그 달 예정 건 전부 확정. 현재는 사람×지급처마다 대화상자.
4. **집행 행 출처 배지와 역링크** (S): 인건비/적립/품의 표시, 원본 화면으로 이동. B2·D5 해결.
5. **원클릭 상태 버튼의 되돌리기 토스트** (S): 청구일·완료일·보완 버튼 후 10초 되돌리기.
6. **영향 미리보기 확인 창** (M): 확정·확정 취소·삭제 시 연결 집행 번호, 증빙 수, 차단 여부를 보여주고 버튼에 결과 명시. 네이티브 confirm/prompt 대체.
7. **모든 요약 표 CSV/XLSX** (S): 인건비 현황·계획표·선급, 태그 표, 예산 요약. 숫자는 숫자형으로, 기준일 줄과 소계 구분 열 포함.
8. **월 마감 보고서 인쇄 보기** (M): A4 가로 한 장. 센터·재원·기간·기준일·작성자, 재원×예산목 표(총계 포함), 당월/누계, 대기 품의 경과, 보완 건수, 적립금 잔액, 선급/미지급.

### 다음 (중간 노력)
9. **계획표 키보드·직접 입력** (M): 화살표 이동, Enter로 편집, 단일 지급처 칸은 바로 타이핑, "기준급여로 채우기". 범례 클릭으로 부족/초과/미배정 필터.
10. **집행내역 다중 선택 일괄 청구/완료** (M): 월말 처리 속도.
11. **결의 vs 지출완료 분리 열** (S): 지출완료일 기준 현금 지출과 미지급(결의−지출)을 재원×예산목에 표시.
12. **집계 대사 패널** (S): 대시보드 집행 = 집행내역 합계 − 제외 행(외부 지급처·예산목 외) ± 적립 연결, 각 행으로 드릴다운.
13. **소진 예측** (S): 월평균 집행으로 연말 잔액·소진 예상월, 차트에 점선 투영. 인건비는 기준급여×남은 재직월 vs 남은 인건비 예산.
14. **대기 품의 경과 목록** (S): N일 이상 대기 건을 품의자·재원별로.
15. **인건비 지급처별 귀속월 보기와 연간 소요 전망** (M): "12월까지 급여를 감당할 수 있나"에 답.
16. **날짜 입력 보조** (S): 오늘/어제/직전 입력일 칩, Alt+↑↓로 하루 이동, 청구/완료 버튼 Shift+클릭 시 날짜 선택.

### 나중 (큰 노력 또는 스키마 변경)
17. **품의번호 연결 열** (M/L): 비고 텍스트 대신 실제 연결, 부분·분할 전환, 품의 잔액.
18. **다년도 재원** (M/L): 재원·예산변동에 연차/사업기간, 당해 연차 예산 vs 전체 사업비, 이월, 집행 기한.

## 3. fable 종합 의견
- 가장 먼저 손볼 것은 **A군(숫자 정의)** 이다. 화면마다 다른 가용잔액은 담당자와 센터장의 신뢰를 한 번에 잃게 한다. "기준일 하나, 공용 계산 함수 하나" 원칙으로 A1~A4·A6~A8을 함께 고치는 편이 개별 패치보다 싸다.
- **B1(UTC 날짜)·B2(연결 집행 수정)·B4(가려진 토스트)** 는 작은 수정으로 즉시 막을 수 있는 실수 경로라 같은 묶음으로 처리한다.

- 용어는 **가용잔액 / 확정잔액·예정잔액 / 선급(+)·미지급(−)** 세 묶음으로 정리하고, README를 UI 라벨에서 자동 추출하듯 맞춘다.
