# 신청 › 기타 탭 점검 (2026-10-16, 용도 적합성·동등성/데이터 2개 검토 취합)

대상: 기타 하위 탭 목록·폼·드로어·결재·품의 전환. 기타는 전용 코드가 없고 장비 폼·흐름을 그대로 쓴다(전용 분기는 드로어 첨부 안내 문구 1곳). 스크래치 장부(QA 복사본, 드라이브 mock)로 API 65건 + 브라우저 검증, 코드 수정 없음. 증빙: scratchpad `rv_etc/`(스크린샷 01~12), `rv_par/`(api_test.py, out1.txt). 페이지 오류 0(동등성 검토의 마지막 브라우저 구간은 중단되어 미집계).
결론: 기능은 장비와 한 치도 다르지 않게 동작한다(저장·계산·승인·전환·정렬·필터·검색·배지 정상, 기타 전용 데이터 불일치 0). 문제는 라벨·힌트·안내문이 전부 "물건 구매" 전제라 구독·용역·수수료·해외 결제 신청자에게 맞지 않는 것이다.

## P2 — 수정 권장
**문구·폼 (기타 분기)**
- 규격 힌트 "모델·사양"이 구독·용역에 무의미, 기간·단위·좌석을 적을 곳이 없어 품목에 "(3석)"을 끼워 넣음 → 기타 힌트 "기간·단위·플랜 (예: 월 3석, 1년, 2시간)", 드로어 라벨 "규격/단위" (request.js 70, 660).
- 수량 단위가 없어 목록의 "12"가 12개인지 12개월인지 모름 → 기타 수량 힌트 "개·월·회·석 — 단위는 규격에" (request.js 71).
- 연구원 안내문·저장 토스트가 "견적서" 고정, 드로어 첨부 힌트만 다름 → 기타 분기 "견적서·인보이스·요금제 안내·청구서" (reqResearcherNote, requestSavedMsg).
- 희망일 힌트 "필요한 날짜" → 기타 "시작·작업 희망일". 품의 전환 preset에 `지출예정일 = 희망일` 전파(장비도 이득) (request.js 68, 552-556).
- 해외 결제의 원화 환산 근거를 적을 곳이 없음 → 규격 힌트 안내(D3).
- 품의 전환 적요 = 품목만 → 기타는 "품목 (규격)" + 수량>1이면 "× 수량", 비고에 사유 1줄 (request.js 552-556).
- 단가 라벨 "단가 (부가세 포함)"이 해외 서비스에서는 사실과 다름 → 기타 "단가 (실제 낼 금액)".

**데이터·서버 (장비 공통)**
- 승인 건의 구분 변경이 재결재가 아님(서버·화면) → D4에 따라 `REAPPROVE_COLS`·`REQ_APPROVAL_KEYS`에 구분 추가 (store.py 96, request.js 11).
- API/MCP로 비소모품 행에 온라인코드·상품코드·상품링크가 저장됨(화면은 비움, 서버는 구매처만) → `구분 != 소모품`이면 세 열 "" (store.py 1317-1319).
- 단가·부가세액 소수 허용 → 금액 소수가 품의로 전파 → `_won_int` 적용 (store.py 1355, 1364).
- 다른 탭에서 구분을 바꿔 저장하면 현재 목록에 안 보이고 토스트는 "저장했습니다"뿐 → D5 (request.js requestAfterSave).
- 기타→학회 전환 시 서버가 규격을 지우지 않아 되돌리면 재등장 → 학회 분기에서 `규격 = ""` (store.py 1342-1350).

## P3
- 드로어 "규격 -" 행은 비면 숨김. 1024 폭 + 드로어에서 금액 열이 가로 스크롤 뒤로 숨음(장비 공통).
- 생성 시 부가세 Y + 부가세액 0을 '0원 입력'으로 저장(수정 경로의 0 = 미입력과 다름, 화면 영향 없음) → 생성도 0 = 기본값.
- 부분 PUT(비고만)이 "신청인 필수" 400 → 빠진 열은 existing으로 채우기. 승인 건의 사유·신청인 변경은 재결재 아님(설계로 보임) → 주석 명시.
- 폼에서 부가세액 0 → 체크 해제 → 재체크 시 0 유지 → 0이면 자동값으로 (request.js fillVat).

## 잘 된 점
- 기타는 장비와 코드 경로를 완전히 공유해 금액·부가세·결재·전환·잠금 규칙이 같음(API 65건 중 기타 전용 불일치 0). 혼합 구분 일괄 승인·품의 전환이 부가세 메모까지 정확.
- 저장 시 구분에 맞게 정리(구매처·코드·상세 비움)되고 폼의 구분 전환이 숨은 칸 값을 보존. 빈 상태·배지·선택 바·도움말이 구분명을 치환해 추가 코드 없이 동작.
- 서버가 상태·결재인·주문·연결품의 열을 어떤 경로에서도 덮어쓰지 못하게 강제.
