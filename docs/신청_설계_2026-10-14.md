# 신청 화면 설계 (2026-10-14)

목적: 담당자가 품의를 작성하기 전에 연구원들이 필요한 지출을 신청하는 화면. 세목 구분 없이 항목·단가·수량·사유와 간단한 첨부(견적서·인보이스·요금제 정보)를 받는다. 참고: `ref/소모품 구매관리대장.xlsx`(구입신청→결재→주문·배송, 주문 묶음=적립금 사용, 발주서), `ref/학회여비계산기V2.html`(여비 산출·제출 서류 체크리스트). 의도만 차용하고 코드는 새로 작성.

## 사용자 결정
| 항목 | 결정 |
|---|---|
| 위치 | 상단 헤더 **신청** 전환 버튼, 별도 주소 `/request`. 하위 탭 [장비] [소모품] [학회] [기타] |
| 신청인 | 이름 자유 입력(자동완성). 연구원 계정(이름+PIN)은 아주 나중 과제 |
| 관련 과제 | 재원 목록에서 선택 + 직접 입력 허용 |
| 상태 | 신청 → 승인 / 반려(사유) → 품의전환 → 완료(연결 품의가 집행완료되면 자동) |
| 첨부 | 구글 드라이브, 증빙과 같은 계정. 폴더 `신청/YYYY/신청번호/` |
| 소모품 | 온라인코드·상품코드·상품링크 열, 주문 단계(주문번호·주문일·배송일), 주문 묶음을 적립금 '사용'으로 기록, 발주서 출력. **2단 메뉴 [신청 | 주문]** (2026-10-14 사용자 요청 "신청과 주문 하위 탭 분류", 담당자만): 신청 보기 = 목록·필터·선택 막대([주문 생성])·상세 패널, 주문 보기 = 주문 표 전용(연도·거래처·상태 주문 중/배송 완료·검색, 'n건 · 주문금액 합계', 신청번호 → 신청 보기의 상세 패널). 선택은 `localStorage ledger-rtab-sub`에 기억, 연구원 화면은 2단 메뉴 없이 신청 목록 |
| 소모품 구매처 (2026-10-14 추가) | 알파몰·드림디포 두 곳에서 신청 가능, 시기에 따라 한 곳만 가능 → 담당자가 설정에서 관리. `신청` 시트에 `구매처` 열(상품링크 다음, 이전 장부는 맨 끝에 추가). 설정 `REQUEST_SUPPLIERS`(목록, 기본 `알파몰,드림디포`) · `REQUEST_SUPPLIERS_OFF`(현재 이용 불가, 구매처별 '현재 신청 가능' 체크) · `REQUEST_SUPPLIER_NOTE`(연구원 안내). 소모품은 구매처 필수·목록 안·이용 불가면 거부(기존 값 유지 수정은 허용), 비소모품은 비움. 한 주문 = 같은 구매처, 주문 거래처 기본값 = 구매처, 주문번호 앞자리 알파몰→`알파`, 드림디포→`드림`, 그 밖에는 거래처 앞 두 글자. 발주서 머리글: 발주처(설정) · 구매처(주문 거래처) |
| 학회 | 신청 정보 + 여비 계산기 이식(기내박·환율·도시 등급·서류 체크리스트). 관용차량 항목은 제외(사용자 지시). 산출 금액이 신청 금액. **구현 2026-10-14 (`static/conf.js`)**: 이동 구간마다 출발·도착의 장소·시간대(주요 IANA 목록 + 기타 직접 입력, `Intl`로 검사)·현지 일시 → UTC 환산(서머타임 반복 보정), 현지/KST 나란히 표시. **기내박·여행일수는 한국 시각 기준**(기내박 = 항공·선박 구간의 KST 날짜 변경 수, D = 첫 출발~마지막 도착 KST 날짜 수, 도착≤출발이면 주의 + 0박). 산식은 원본과 같음(일비 15일 초과 감액 제17조, 식비 1끼 = 1/3, 숙박 min(결제액, 상한×박수), ₩/$·환율·기준일, 부대비, 외부 지원금 차감). `상세` = `{…학회 칸, v:1, in, out:{합계,여비,부대비,외부지원,일수,박수,기내박,등급,환율,기준:"KST",lines,docs,…}, 합계}`, 금액 = 합계(잠금), '계산 초기화'로 해제. 상세 패널 요약 + '산출 내역 보기'(보기 전용, A4 인쇄: 기본 정보/산출 내역/안내/서류 체크리스트). 원본과 다른 점: 출장 시작·종료일 칸 대신 이동 구간에서 계산, 학회 기간이 출장 기간 밖이면 차단 대신 주의, 입력값 파일·엑셀 내보내기 없음 |
| 장비·기타 | 같은 폼: 품목·규격(모델)·단가·수량·사유·희망일·첨부 |
| 승인·반려·전환 | 담당자 모드에서만. 회계대장 모드에서 헤더 버튼으로 들어오면 자동 담당자, `/request` 직접 접속은 연구원 화면(신청 목록·상태·본인 신청 추가/수정만, 헤더의 인건비·설정·AI 버튼 숨김) |
| 품의 전환 | 신청 1건 또는 여러 건을 골라 품의 1건으로. 소모품은 주문 묶음 = 품의 1건 |

## 시트
- `신청`: 신청번호(R-YYYY-NNN), 구분(장비/소모품/학회/기타), 상태(신청/승인/반려/품의전환/완료), 신청인, 신청일, 관련과제, 품목, 규격, 단가, 수량, 금액, 부가세구분(Y/N), 부가세액, 사유, 희망일, 온라인코드, 상품코드, 상품링크, 결재인, 결재일, 반려사유, 주문번호, 연결품의번호, 첨부폴더, 첨부목록, 상세(JSON: 학회 계산기 입력·산출), 비고
- `주문`: 주문번호(알파-YYYYMMDD-NN 자동), 주문일, 배송일, 거래처, 주문금액, 결제금액, 적립금사용(Y/N), 신청번호목록(쉼표), 비고
- `신청첨부`: 신청번호, 파일명, 원본파일명, 드라이브파일ID, 크기, 업로드일, 비고

- `메타`(숨김): 키/값. `신청번호최고-YYYY` = 그 해 발급한 최고 신청번호 (지운 번호·드라이브 폴더 재사용 방지)

## 점검 반영 (2026-10-14, `점검_2026-10-14_신청_장비.md` 백엔드 항목)
| 항목 | 결정·구현 |
|---|---|
| 부가세 (사용자 결정) | `부가세구분` Y/N(기본 N)·`부가세액`을 `금액` 뒤에. N: 금액 = 단가×수량, 부가세액 비움. Y: 단가 = 공급가, 금액 = 단가×수량 + 부가세액(없으면 round(단가×수량×0.1)). 서버가 다시 계산. 학회는 N 고정. 이전 장부는 열 이름 기준으로 맨 끝에 추가. 발주서 줄·품의 전환 비고("부가세 별도 n원", Y일 때만)에 반영, 적요는 그대로 |
| 상태 이름 (사용자 결정) | '신청'으로 통일 ('결재 대기'·'승인 대기' 쓰지 않음) |
| 수식 주입·제어문자 | 모든 시트의 글 칸: `= + - @` 시작은 문자열+따옴표 접두, 엑셀 금지 제어문자 제거. 전역 예외 처리기 → `{"detail": "서버 오류: …"}` 500 |
| 승인 후 수정 | 품목·규격·단가·수량·금액·관련과제·부가세 변경 시 '신청'으로, 결재인·결재일 비움, 응답 `reapproval: true`. `extra.keep_approval=true`면 유지(화면이 담당자에게 확인) |
| 끊긴 연결 품의 | 연결품의번호의 품의가 없으면 '승인'으로 보고 승인 취소·전환·주문·삭제 허용, 저장 시 연결 정리 |
| 첨부 | 올리기: 신청·반려·승인. 지우기: 신청·반려(승인은 `extra.admin`). 신청당 20개·100MB(413). 확장자 정제. 업로드 `expect` 선택 |
| 검증 | 유한값, 0 < 단가 ≤ 1조(학회 제외), 수량 양의 정수, 글 32,767자 초과 오류, 결재일 ≥ 신청일, 숫자 오류는 실제 열 이름 |
| 번호 | 연도별 최고값을 `메타` 시트에 보관 → 지운 마지막 번호 재사용 없음 |
| 일괄 결재 | `POST /api/request/batch-action` (한 번 저장, 전부 또는 전무) |
| 권한 | API에 인증 없음. 연구원 화면은 UI 구분일 뿐 (README에 명시) |

## 동작
- 승인/반려: 결재인·결재일(오늘) 기록, 반려는 사유 필수. 승인 취소 가능(품의전환 전).
- 품의 전환: 선택한 승인 건들로 품의 폼을 채워 열고(적요=품목 나열, 금액=합계, 품의자=신청인, 비고=신청번호 목록), 저장 시 서버가 품의 생성 + 신청 상태 품의전환·연결품의번호 기록(한 트랜잭션). 품의가 집행완료되면 신청은 완료로 표시(읽을 때 계산).
- 소모품 주문: 승인된 소모품 건을 골라 주문 생성(주문번호 자동, 거래처 기본 '알파몰', 주문금액=합계, 결제금액 입력). '적립금 사용' 체크 시 적립금 시트에 사용 1건(거래처·금액·적요 "소모품 주문 {주문번호}"·증빙번호=주문번호). 배송일 등록 시 해당 신청 완료. 발주서: 주문 묶음을 인쇄용 표(순번·온라인코드·상품코드·품목·수량·신청번호, 발주처·배송지·담당자는 설정값, 구매처는 주문 거래처)로 출력.
- 첨부: 증빙 업로드와 같은 방식(드라이브 폴더 자동 생성, 파일명 `신청번호_품목_원본명`), 썸네일 재사용.
- 학회: 폼의 [여비 계산기] 대화상자(기본 정보·학회 기간·이동 구간(시간대 환산)·숙박·식비·부대비용·외부 지원금 → 요약 띠·산출 내역·안내·서류 체크리스트). 입력과 산출을 `상세` JSON에 저장, 산출 합계를 금액에(잠금). 테스트: scratchpad `test_conf.py`.
