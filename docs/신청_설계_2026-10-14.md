# 신청 화면 설계 (2026-10-14)

목적: 담당자가 품의를 작성하기 전에 연구원들이 필요한 지출을 신청하는 화면. 세목 구분 없이 항목·단가·수량·사유와 간단한 첨부(견적서·인보이스·요금제 정보)를 받는다. 참고: `ref/소모품 구매관리대장.xlsx`(구입신청→결재→주문·배송, 주문 묶음=적립금 사용, 발주서), `ref/학회여비계산기V2.html`(여비 산출·제출 서류 체크리스트). 의도만 차용하고 코드는 새로 작성.

## 사용자 결정
| 항목 | 결정 |
|---|---|
| 위치 | 상단 헤더 **신청** 전환 버튼, 별도 주소 `/request`. 하위 탭 [장비] [소모품] [학회] [기타] |
| 신청인 | 이름 자유 입력(자동완성). 연구원 계정(이름+PIN)은 아주 나중 과제 |
| 관련 과제 | 재원 목록에서 선택 + 직접 입력 허용 |
| 상태 | 신청 → 승인 / 반려(사유) → 품의전환 → 완료(연결 품의가 집행완료되면 자동) |
| 첨부 | 구글 드라이브, 증빙과 같은 계정. 폴더 `신청/YYYY/신청번호/` |
| 소모품 | 온라인코드·상품코드·상품링크 열, 주문 단계(주문번호·주문일·배송일), 주문 묶음을 적립금 '사용'으로 기록, 발주서 출력 |
| 학회 | 신청 정보 + 여비 계산기 이식(기내박·환율·도시 등급·서류 체크리스트). 관용차량 항목은 제외(사용자 지시). 산출 금액이 신청 금액 |
| 장비·기타 | 같은 폼: 품목·규격(모델)·단가·수량·사유·희망일·첨부 |
| 승인·반려·전환 | 담당자 모드에서만. 회계대장 모드에서 헤더 버튼으로 들어오면 자동 담당자, `/request` 직접 접속은 연구원 화면(신청 목록·상태·본인 신청 추가/수정만, 헤더의 인건비·설정·AI 버튼 숨김) |
| 품의 전환 | 신청 1건 또는 여러 건을 골라 품의 1건으로. 소모품은 주문 묶음 = 품의 1건 |

## 시트
- `신청`: 신청번호(R-YYYY-NNN), 구분(장비/소모품/학회/기타), 상태(신청/승인/반려/품의전환/완료), 신청인, 신청일, 관련과제, 품목, 규격, 단가, 수량, 금액, 사유, 희망일, 온라인코드, 상품코드, 상품링크, 결재인, 결재일, 반려사유, 주문번호, 연결품의번호, 첨부폴더, 첨부목록, 상세(JSON: 학회 계산기 입력·산출), 비고
- `주문`: 주문번호(알파-YYYYMMDD-NN 자동), 주문일, 배송일, 거래처, 주문금액, 결제금액, 적립금사용(Y/N), 신청번호목록(쉼표), 비고
- `신청첨부`: 신청번호, 파일명, 원본파일명, 드라이브파일ID, 크기, 업로드일, 비고

## 동작
- 승인/반려: 결재인·결재일(오늘) 기록, 반려는 사유 필수. 승인 취소 가능(품의전환 전).
- 품의 전환: 선택한 승인 건들로 품의 폼을 채워 열고(적요=품목 나열, 금액=합계, 품의자=신청인, 비고=신청번호 목록), 저장 시 서버가 품의 생성 + 신청 상태 품의전환·연결품의번호 기록(한 트랜잭션). 품의가 집행완료되면 신청은 완료로 표시(읽을 때 계산).
- 소모품 주문: 승인된 소모품 건을 골라 주문 생성(주문번호 자동, 거래처 기본 '알파몰', 주문금액=합계, 결제금액 입력). '적립금 사용' 체크 시 적립금 시트에 사용 1건(거래처·금액·적요 "소모품 주문 {주문번호}"·증빙번호=주문번호). 배송일 등록 시 해당 신청 완료. 발주서: 주문 묶음을 인쇄용 표(순번·온라인코드·상품코드·품목·수량·신청번호, 구매처·배송지·담당자는 설정값)로 출력.
- 첨부: 증빙 업로드와 같은 방식(드라이브 폴더 자동 생성, 파일명 `신청번호_품목_원본명`), 썸네일 재사용.
- 학회: 폼 안에 계산기 섹션(기본 정보·기간·이동 구간·숙박·식비·부대비용·외부 지원금 → 산출 내역·서류 체크리스트). 입력과 산출을 `상세` JSON에 저장, 산출 합계를 금액에.

## 화면
- 공통 목록 열: 신청번호, 상태, 신청인, 신청일, 관련과제, 품목(아래 규격/사유 요약), 수량, 금액, 첨부 수, 결재인/결재일, 연결 품의. 필터: 상태·신청인·과제·연도·검색. 더블클릭 수정(신청 상태일 때만 신청인 수정 가능, 담당자는 항상).
- 담당자 모드 툴바: [승인] [반려] [품의 전환(선택)] [주문 생성(소모품)], 체크 열. 연구원 모드: [신청 추가]만.
- 상세 드로어 재사용 구조(신청 정보·첨부 목록·업로드·상태 이력 대신 결재 정보).
