# 인건비 관리 기능 설계 (2026-10-13)

참고 자료: `01 in progress/인건비대장` (엑셀 `2026 의료인공지능센터 직접인건비 현황`, SQLite 프로토타입). 의도 파악에만 사용했고 코드는 이식하지 않음.

## 파악한 의도
- 센터 인력의 직접인건비를 **지급월 × 이름 × 지급처(재원) × 금액** 단위로 관리하고, 한 사람의 급여를 여러 재원에 나눠 배분한다.
- 지급한 것(확정)과 앞으로 지급할 것(예정)을 구분하고, 지급처별로 인건비 예산 대비 누적 확정·예정·예정잔액을 본다.
- 사람별로 기준급여·입사/퇴사와 월별 배분 합계를 비교해 미배정·부족·초과를 본다.
- 장부 재원이 아닌 외부 지급처(AI사업단, 연구지원-교수 등)도 함께 집계한다.
- 선급/미지급 급여 흐름을 파악한다.

## 사용자 결정
| 항목 | 결정 |
|---|---|
| 위치 | 상단 헤더 오른쪽 **인건비** 전환 버튼, 별도 주소 `/labor`. 기본 메뉴바와 분리된 하위 탭 [계획표] [지급 원장] [인원] [지급처] |
| 집행내역 연동 | 확정 시 집행내역에 **건별 1행** 자동 기록(사람×지급처×월). 예산목은 인원의 내부/외부 구분으로 자동(내부인건비(공통)/외부인건비(공통)). 외부 지급처 건도 재원 열에 지급처코드로 기록하되 예산 집계에서는 제외 |
| 인건비 예산 | 기본은 예산변동의 내부인건비+외부인건비 합계, 재원 탭 **인건비예산** 열에 값을 넣으면 그 값 우선. 외부 지급처는 지급처 목록의 인건비예산(비우면 관리 안 함) |
| 상태 | 예정 / 확정만. 취소는 삭제(확정 건 삭제 시 연결 집행도 함께 삭제, 증빙이 있으면 차단) |
| 인원 정보 | 이름, 내부/외부 구분, 입사일·퇴사일, 기준급여(월액·적용기간, 여러 구간 가능), 이월선급 |
| 계획 입력 | 기간 일괄 생성, 전월 계획 복사, 계획표 셀 편집, 건별 추가 폼 |
| 월 | 지급월 + 귀속월 (계획표는 귀속월, 원장·지급처 현황은 지급월 기준) |
| 선급/미지급 | 자동 계산(귀속월 기준 발생액 − 지급월 기준 확정 지급액, 이월선급 포함) + 수동 조정 건 |

## 시트
- `인원`: 이름, 인건비구분, 입사일, 퇴사일, 이월선급, 비고
- `기준급여`: 이름, 시작월, 종료월, 월액, 비고
- `지급처`: 지급처코드, 지급처명, 인건비예산, 비고
- `인건비지급`: 지급월, 귀속월, 이름, 지급처, 금액, 상태, 지급일, 연결거래번호, 비고
- `인건비조정`: 월, 이름, 금액, 사유 (+ 선급 / − 미지급)
- `재원` 시트에 `인건비예산` 열 추가

## 계산
- 지급처별 현황(연도, 지급월 기준): 예산, 확정, 예정, 확정잔액 = 예산 − 확정, 예정잔액 = 예산 − 확정 − 예정
- 계획표 셀(귀속월): 배분 합계(예정+확정) vs 기준급여 → 미설정 / 정상 / 부족 / 초과
- 선급·미지급(사람, 연도, 기준월까지): 이월선급 + 확정지급 누계(지급월) − 발생 누계(귀속월, 기준급여×재직월) + 조정 합 → 양수 선급, 음수 미지급
